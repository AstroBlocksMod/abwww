# Roadmap

Finished items are checked off where they are.

## MVP

- [x] Accounts: register, sign in, profile page, settings
- [x] Projects: upload .sb3, play in a sandboxed player, open in the editor, download, remix
- [x] Visibility: private, unlisted, public; recently shared on the home page
- [x] Every save is a git commit; history page with restore
- [x] Scratch account linking by verification comment
- [x] Import your own Scratch projects
- [x] Federation: actors, followers, NodeInfo, Create(Note) when a project goes public
- [x] Docker compose for self-hosting
- [ ] Editor saves straight to the site (needs the editor to read its hosts from the URL)
- [ ] Thumbnails

## Community

- [ ] Comments on projects and profiles
- [ ] Studios
- [ ] Loves and favorites
- [ ] Search
- [ ] Moderation tools and reports
- [ ] Follow local users, and show remote followers on profiles

## Version control

- [ ] Diffs between versions, readable per sprite
- [ ] Branches and named versions
- [ ] Git smart HTTP so projects can be cloned

## Platform

- [ ] Passkeys and email recovery
- [ ] Object storage backend for assets and git
- [ ] Vercel deployment
